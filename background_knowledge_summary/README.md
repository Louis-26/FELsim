# Twiss parameters

## beta
$\beta_x$ means the beam size function in x

$\sigma_x=\sqrt{\beta_x\epsilon_x}$ where $\sigma_x$ is the beam size in x as the dispersion in x


## alpha
$\alpha_x$ means the beam focusing/divergence function

$\alpha_x=-\frac{1}{2}\frac{d\beta_x}{ds}$ where s is the distance along the beam path


 

## gamma
$\gamma$ means the angular spread function

with $\gamma x^2+2\alpha xx'+\beta x^2=\epsilon$, we have $\beta\gamma-\alpha^2=1$

$\gamma=\frac{\alpha^2+1}{\beta}$

then $\sigma_{x'}=\sqrt{\gamma_x\epsilon_x}$

## emittance
$\epsilon$ is the emmittance of the beam, which measure the beam spread in position and angle

$\epsilon=\langle x \rangle \langle x' \rangle - \langle xx' \rangle$
